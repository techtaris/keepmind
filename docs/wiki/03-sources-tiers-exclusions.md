# Sources, tiers & exclusions

[← Wiki home](../README.md) · Config: `config/secondbrain.json` (`roots`, `enabled_tiers`), `config/source-register.json`, `config/exclusions.json`

## Source folders
Only the folders listed in `roots` are read, recursively, and only **read**: the Seatbelt profile denies writes to them, and reads anywhere else in your home folder.

## Tiers
`source-register.json` maps path prefixes (relative to your home folder) to a tier; first match wins; unlisted paths are **A**. Only tiers in `enabled_tiers` are indexed (default `["A"]`).

| Tier | Meaning | Default |
|---|---|---|
| **A** | Your own projects and notes | On |
| **A-docs** | Folders where only `*.md` / `*.txt` are indexed (e.g. a model store) | On with A |
| **V** | Notes in a [notes vault](15-notes-vault.md) (category folders; Personal and, if you choose, Clients/Sales excluded) | On when a vault is configured |
| **W** | Work / client / employer material | Off — enable only with authorization |
| **P** | Personal or raw data: chat exports, transcripts, career files | Off |
| **R** | Third-party / downloaded repositories | Off |
| **X** | Never (the instance folder itself) | Never |
| **D** | Derived knowledge generated by `sb` (`knowledge/`) | On with A |

## Never opened (by name or type)
- **Secrets:** `.env` and every `.env.*` (templates often contain real-looking credentials), keys and certificates (`*.pem`, `*.key`, `*.p12`, `id_rsa*`…), `.npmrc`, `.pypirc`, `.netrc`, `.git-credentials`, Terraform state/vars, `secret(s).*`, `*credential*.json`, `client_secret*.json`, `service-account*.json`, agent `settings*.json`.
- **Private data stores:** databases (`*.sqlite`, `*.db`…), email (`*.eml`, `*.mbox`, `*.msg`), chat exports.
- **Noise:** lock files, minified/map files, binaries and media, files over the size limits (2 MB text; 256 KB JSON/YAML/HTML/CSV; 50 MB office).
- **Folders never entered:** `.git`, `node_modules`, virtualenvs, build/dist/cache folders, browser profiles (`.chrome*`), `.obsidian`, and every other dot-folder except `.github`, `.agents`, and the `skills/commands/agents` parts of `.claude`, `.codex`, `.cursor`.
- **Symlinks:** recorded, never followed.

## Content scan (after parsing, before indexing)
| Match | Action |
|---|---|
| High-confidence secret (AWS/GitHub/Slack/Google keys, `sk-…` keys, PEM private keys, JWTs, npm tokens), checked in the raw bytes **and** in the extracted text, so keys inside .docx/.xlsx/.pptx/.pdf are caught | Whole file **quarantined**: logged with path, rule, line and file hash — never the value |
| Low-confidence (URLs with embedded passwords, literal `password = "…"` assignments) | Span **redacted** to `«REDACTED:rule»`; file indexed with `redacted=1` |

`sb quarantine` lists quarantined files. If a match is a real key, rotate it at the provider.
